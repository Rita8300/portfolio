# 宮本琉太 ポートフォリオ

福岡大学 法学部の宮本琉太のポートフォリオサイト。Next.js（Pages Router）の1ページ構成。

## 構成

- `pages/index.js` — ページ本体。マークアップ・CSS（styled-jsx global）・挙動（表紙 / スクロール表示 / Projects開閉 / カードチルト / アドレスコピー）を1ファイルにまとめている。
- `pages/_document.js` — `<html lang="ja">` の指定のみ。
- `next.config.js` — `output: 'export'`（静的書き出し）。

## 開発

```bash
npm install
npm run dev      # http://localhost:3000
```

## ビルド（静的書き出し）

```bash
npm run build    # out/ に静的ファイルを生成
```

`out/` の中身をそのまま静的ホスティング（Lolipop など）のドキュメントルートに置く。

## 掲載方針

- 本名・学年・メールアドレスは公開。
- GitHub へのリンクは載せず、Skills 内で「公開・運用は今後強化」とだけ記載。
- キャッチコピーは本人が選んだ一文をそのまま使用。
- インターン企業は「参加・研究した企業」表記（「インターンした」と断定しない）。

## 制約

- スマホ 375px で横スクロールが出ないこと。
- コントラスト比 4.5:1 以上を維持。
- 外部ライブラリ・画像なし。
- スクロール表示アニメは、ハッシュジャンプでも取りこぼさないようフォールバックあり（`IntersectionObserver` + 手動スイープ）。
- JS 無効時は `<noscript>` で表紙を隠し、全要素を表示。
